Help

How to use the current local browser arena.

1. Load your game

Select your legally obtained original NHL94 Genesis ROM in the arena. The emulator runs locally in your browser; your ROM is not uploaded or included with this site.

This version accepts the original raw .bin, .md or .gen ROM, up to 4 MiB. ZIP files, interleaved SMD files, roster hacks and other ROM revisions are not supported yet.

2. Configure controllers

Controller 1 defaults to Human/Home and controller 2 to Diagnostic bot/Away. Each active slot can be Human, an available bot, or None. Controllers 3 and 4 are disabled until four-player support is added.

Loading your ROM restores the bundled Sabres vs Mighty Ducks manual-goalie match. Choose Home or Away beside each slot to change its in-game controller assignment immediately, without selecting players in the game's menus.

With one Human slot, keyboard, on-screen controls and your selected gamepad all control that slot. With two Human slots, keyboard/on-screen input goes to controller 1 and the gamepad to controller 2. None releases a controller; teams with no assigned controller return to the game's built-in CPU.

For Bot vs Bot, choose a bot for each slot and press Play. Changing controller setup pauses playback and applies the new ownership before the next frame. Four-player support is not enabled yet.

3. Choose an input device

Use the keyboard or select a browser-detected gamepad in Step 3.

  • Arrow keys: D-pad.
  • Z / X / C: Genesis A / B / C.
  • Enter: Genesis Start, including the in-game pause menu.
  • Standard gamepad X / A / B: Genesis A / B / C; Start: Genesis Start.

If your gamepad does not appear, click inside the arena and press a controller button. Browser activation may be required even when Linux recognizes the device.

For an M30 receiver or another non-standard mapping, expand Gamepad setup and live inputs, select Set up buttons / D-pad, and follow the eight prompts. Check the live Genesis input before playing. Custom mappings last for the current tab.

Playback and game statistics

Play/Pause starts or pauses emulation. Step one frame advances exactly one native frame. Restart match restores the default match and starts a new recording. Sound is optional and begins after a user action.

The Game Stats table beneath Bot Configuration shows Home/Away totals from the game's native team counters, including every pause-menu Game Statistics row.

Bot Configuration is a preview only. Its frequency, AI Goalie and player-ratings controls are disabled and do not affect bot execution yet.

Hiding the arena tab pauses emulation. The arena's Bots, Help and About links open a new tab so reading them does not unload your match.

4. Record and replay

Download the input replay in Step 4. Load it again with the same ROM, starting state and emulator build, then press Play. Replays restore the saved start, apply recorded controller-assignment changes and reproduce the recorded inputs without running the bots again.

Replay playback disables live controller setup. Recordings are limited to 108,000 native frames and replay files to 4 MiB. Replays contain inputs and compatibility identifiers, not the ROM or bot source.

Current scope

This is a local browser test arena using Genesis Plus GX WebAssembly. Only the diagnostic bot is currently available. Classic, learned models, online challenges and ranked competitions are not implemented yet.
