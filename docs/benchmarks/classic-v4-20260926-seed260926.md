# ClassicAI v4 benchmark — 2026-09-26

The current restored V4 controller in `nhl94-ai` completed all 140 trials.
Each trial was a 300-second first period of original Genesis NHL94, using
FILTERED buttons repeated for four emulator frames and ROM seeds 260926–260945.
These are period results, not full-game win rates. No controller tuning was
performed during this benchmark.

| Opponent / V4 team–CPU team | Periods | V4 wins–draws–losses | V4 goals for–against |
| --- | ---: | --- | --- |
| classic-v2 | 40 | 21–15–4 | 41–18 |
| classic-v3 | 40 | 17–16–7 | 44–22 |
| penguins-senators (CPU) | 20 | 11–5–4 | 24–11 |
| senators-penguins (CPU) | 20 | 4–3–13 | 10–29 |
| nordiques-canadiens (CPU) | 20 | 7–4–9 | 16–20 |

V4 had a winning record against both scripted opponents in this sample.
Against the CPU overall it went 22–12–26,
with 50 goals for and 60 against.
Ottawa against Pittsburgh was its weakest tested matchup. Team changes also
change the opponent; these results do not isolate an individual player rating.

V4 averaged 26.28–26.36 microseconds per decision, compared with 241.05 for V2
and 276.49 for V3 (about 9–10 times faster). Timings cover agent decisions only,
exclude emulator/state processing, and were measured during parallel runs.

Across the CPU trials, the ROM recorded 37 V4 one-timers and
15 one-timer goals. There were 115
deliberate setup passes, of which the diagnostic classified 53
as intercepted. One-timer goals accounted for 15/50
of its CPU goals.

The scripted matches used 20 paired seeds per opponent, playing V4 on each side:

| Opponent | V4 side | Wins–draws–losses | Goals for–against |
| --- | --- | --- | --- |
| classic-v2 | home | 14–6–0 | 21–3 |
| classic-v2 | away | 7–9–4 | 20–15 |
| classic-v3 | home | 10–9–1 | 24–9 |
| classic-v3 | away | 7–7–6 | 20–13 |

CPU trials use one human controller and the actual built-in CPU. Home trials
retain normal play's control inference; away trials transfer the joystick and
correct control observations. Both benchmarks use raw emulator progression to
clock zero. No incomplete trial was included. Results are conditional on these
starting saves, rosters, seed range and observation paths.

Reproduce from `/home/mat/github/nhl94-ai` with the installed environment:

```bash
/home/mat/vretro/bin/python -B -m nhl94_ai benchmark --agent classic-v4 --opponents classic-v2 classic-v3 --pairs 20 --seed 260926 --seconds 300 --frame-skip 4 --workers 4 --output /tmp/v4-h2h.json
/home/mat/vretro/bin/python -B -m nhl94_ai benchmark-cpu --agent classic-v4 --trials 20 --seed 260926 --seconds 300 --frame-skip 4 --action-type FILTERED --workers 4 --output /tmp/v4-cpu.json
```

The executed runs used the same harness functions with an output-only progress
wrapper. All 84 package source files were unchanged between the captured source
snapshot and final validation. The reports' own source hashes also match the
current files, and summaries were recomputed from individual trial records.
